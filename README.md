## 🌙 Sobre el proyecto

**Un lugar para nosotros** es una experiencia web interactiva creada para convertir una pregunta especial en un recuerdo inolvidable.

Es una página romántica que permite contar una historia a través de fotografías, recuerdos, una carta personalizada y una propuesta final. Todo acompañado de animaciones suaves, música y una estética visual inspirada en los pequeños detalles.

Este proyecto también está pensado para que puedas utilizarlo como **plantilla y personalizarlo a tu manera**, creando una experiencia única para alguien especial.

## ✨ Características

- 💌 **Carta interactiva:** un sobre animado que revela un mensaje personalizado.
- 📸 **Galería de recuerdos:** fotografías acompañadas de pequeñas historias.
- 🎵 **Música de fondo:** añade una canción especial a la experiencia.
- 🌷 **Sección de deseos:** comparte sueños y momentos que te gustaría vivir.
- 💗 **Pregunta especial:** una propuesta interactiva con una respuesta animada.
- 🎁 **Recuerdo descargable:** genera una tarjeta digital en formato PNG.
- 📱 **Diseño adaptable:** pensado para disfrutarse tanto en celulares como en computadoras.
- ✨ **Animaciones:** transiciones y detalles visuales para darle vida a cada sección.

## 🚀 Instalación y uso

Si quieres utilizar este proyecto como plantilla, sigue estos pasos:

**1. Clona el repositorio**

```bash
git clone URL_DE_TU_REPOSITORIO
```

**2. Entra en la carpeta**

```bash
cd NOMBRE_DEL_PROYECTO
```

**3. Instala las dependencias**

```bash
npm install
```

**4. Inicia el servidor de desarrollo**

```bash
npm run dev
```

Abre la dirección que aparecerá en tu terminal para visualizar la página.

**5. Genera la versión de producción**

```bash
npm run build
```

## 🎨 Personaliza tu propia historia

Puedes adaptar el contenido para crear una experiencia completamente tuya.

**Fotografías**

Reemplaza las imágenes de la carpeta:

```text
public/
└── images/
    ├── recuerdo-1.jpg
    ├── recuerdo-2.jpg
    ├── recuerdo-3.jpg
    └── recuerdo-4.jpg
```

**Música**

Coloca tu canción en:

```text
public/
└── audio/
    └── nuestra-cancion.mp3
```

**Textos y mensajes**

Edita `src/App.tsx` para cambiar:

- Los títulos y mensajes de bienvenida.
- Las descripciones de los recuerdos.
- El contenido de la carta.
- Los deseos y promesas.
- La pregunta final y el mensaje de respuesta.
- Los nombres y el contenido de la tarjeta descargable.

**Diseño**

Modifica `src/styles.css` para personalizar colores, tipografías, tamaños, animaciones y otros detalles visuales.

> 💡 Consejo: utiliza fotografías, mensajes y una canción que tengan un significado especial. Los detalles personales son los que convierten una plantilla en un recuerdo único.

## 🌐 Despliegue

Puedes publicar tu propia versión gratuitamente utilizando [Vercel](https://vercel.com/).

1. Sube tu proyecto a GitHub.
2. Conecta tu repositorio con Vercel.
3. Selecciona Vite como framework.
4. Utiliza `npm run build` como comando de compilación.
5. Configura `dist` como directorio de salida.
6. Pulsa **Deploy**.

¡Y listo! Tendrás tu propia página disponible mediante un enlace público.
